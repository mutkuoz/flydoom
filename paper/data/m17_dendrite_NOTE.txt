GIVING THE DETECTOR A SHAPE

The project's diagnosis of its own motion failure is that the cell adds where
it must multiply: shunting inhibition cancels itself in a point neuron (/1.77
against x1.85, net 1.06). A point neuron is the assumption underneath that.
Every input lands on one node, so WHERE an input arrives cannot be
represented -- and direction is exactly that.

flydoom/compartments_chain.py builds the alternative: each input placed along a
cable by its own retinotopic offset, projected onto that cell's own correlator
axis, with no cell type named in the placement rule. It had never been run,
because lif.py could only express a PAIR of compartments, which cannot carry an
order. It now takes an edge list; tests/test_axial_chain.py checks a two-node
chain against the pair model it generalises.

Drifting grating, 30 deg period, 2 Hz, spiking T4/T5, optic gain 16, anatomical
eye map, 3 compartments. DSI is measured PER EYE and the left eye's sign
flipped back before averaging: the anatomical map mirrors the eyes, so pooling
them cancels the quantity being measured. Reported below is the a-minus-b
separation, which is what a mirror pair must produce.

  g_axial      T4 pair                          T5 pair
            point chain flip shuf          point chain flip shuf
  0.25      .0030 .0010 .0008 .0033        .0047 .0053 .0347 .0057
  1.0       .0030 .0010 .0019 .0045        .0047 .0053 .0679 .0142
  4.0       .0030 .0021 .0145 .0064        .0047 .0366 .0937 .0345
  8.0       .0030 .0077 .0124 .0059        .0047 .0641 .0860 .0471
  16.0      .0030 .0071 .0094 .0064        .0047 .0691 .0781 .0583

WHAT IT SHOWS

1. Compartments work where a point neuron does not. At g_axial 8-16 the OFF
   pathway reaches T5a +0.034 and T5b -0.035 individually, against +0.001 and
   -0.004 as a point neuron: an order of magnitude, with the mirror-pair sign
   structure a correlator requires. The vertical subtypes stay near zero on a
   horizontal grating (0.003-0.006), so this is direction rather than drive.

2. It is NOT the ordering. The shuffled control -- same inputs, same count per
   compartment, only which input lands where destroyed -- reaches 0.058 against
   the ordered 0.069, and the REVERSED cable is consistently the best of the
   three (0.078). What the compartments buy is inhibition sitting electrically
   near the spiking node, which is the "on the path to the output" version of
   the shunt the point neuron cancels. Retinotopic order adds about 20% on top
   of that, at most.

3. The ON pathway barely moves: T4 goes from 0.003 to 0.007-0.012, an order of
   magnitude less than T5. Not explained here.

4. It does not close the gap. The best per-subtype selectivity is about 0.035
   where a fly shows 0.5, so this is roughly 15x short -- better than the ~0.08
   ceiling the parameter sweeps reached, and still not a fly.

The honest reading: the point-neuron assumption WAS costing an order of
magnitude, and the cause is electrotonic placement rather than dendritic
sequence. That is a statement about how this model represents a neuron, not
about the wiring, and it is the first thing in this project to move per-cell
selectivity by more than a factor of two.

Reproduce: experiments/m17_dendrite.py --g-axial 8

THE SHAPE OF THE SLOW ARM (--slow-filter)

Delays from 1.8 to 240 ms have been swept and none rescued direction
selectivity. The SHAPE of the slow arm never had been: a conduction delay
reproduces its input exactly, d steps late, where a fly's slow arm is a
low-pass stage, which smears rather than shifts and keeps no sharp copy of the
past. lif.py can now deliver the slow groups as a one-pole low pass.

T5 a-minus-b separation, g_axial 8:

  slow arm                 point   chain   flipped  shuffled
  80 ms delay (baseline)  .0047   .0641   .0860    .0471
  low pass tau 20 ms      .0022   .0192   .0188    .0140
  low pass tau 80 ms      .0036   .0388   .0504    .0289
  low pass tau 160 ms     .0017   .0319   .0447    .0237

NEGATIVE. The filter is worse than the delay at every time constant tried,
best at 80 ms where it matches the delay it replaces and falling away either
side. A delay preserves the sharp temporal edge the correlator multiplies
against; smearing it costs about 40% of what selectivity there is. The delay
line stays.

(A bug worth recording: the first run of this comparison returned byte-
identical numbers for tau 5 ms and 500 ms, which is impossible. The line that
updates the running average had been lost when an earlier edit aborted, so the
slow arm was delivering a permanently zero trace -- an ablation, not a filter.
Identical outputs across a swept parameter are worth more attention than a
result that merely looks disappointing.)

THE OTHER HALF OF THE DENDRITE (--nmda)

The conductance model makes inhibition divisive, which is the null-direction
half of a correlator. The preferred-direction half is the opposite
nonlinearity: excitation that AMPLIFIES when it lands on a branch already
depolarised, which in a real dendrite is an NMDA-type Mg block lifting. Added
as a voltage-dependent multiplier on the excitatory conductance the wiring
already delivers, evaluated per COMPARTMENT so that with a cable it is local to
the branch:

    g_e -> g_e * (1 + FRAC * sigmoid((v - v_half) / k)),  v_half -48 mV

THE CONTROL THAT MATTERS. A sigmoid with a very large k sits at 0.5 whatever
the voltage, so --nmda 1 --nmda-k 1.0 delivers the SAME mean amplification with
no coincidence detection at all. Any difference between the two is the
nonlinearity; anything they share is drive.

T5 a-minus-b separation, g_axial 8:

    arm         base    nmda 1    flat 1 (=1.5x drive)
    point      +.0047   -.0425    -.0428
    chain      +.0641   -.0010    +.0194
    flipped    +.0860   -.0169    -.0007
    shuffled   +.0471   -.0227    -.0138

NEGATIVE, and cleanly: -0.0425 against -0.0428. The voltage dependence
contributes nothing that a flat gain of the same size does not. Whatever the
supralinear term does here, it does by delivering more excitation.

WHAT THE CONTROL FOUND INSTEAD. Read the same table as a gain sweep, because
that is what it is. A 1.25x flat excitatory gain gives point -0.0289 and a 1.5x
gives -0.0428, against +0.0047 at 1.0: a global scalar, applied to no
particular cell type, moves the pair separation by an order of magnitude AND
REVERSES ITS SIGN. The compartment arms cross over at a different gain from the
point arm, so at 1.5x the chain and the point neuron disagree about which way
the model prefers.

That is a caveat this project has to carry: the sign of the model's direction
preference is not a robust prediction. It survives being read as a mirror-pair
structure, which is what the compartment result claimed, and it does not
survive being read as an absolute direction.

    python experiments/m17_dendrite.py --g-axial 8 --nmda 1 [--nmda-k 1.0]

HOW MUCH OF IT IS THE ORDER, WITH MORE THAN ONE SHUFFLE (--shuffle-seeds)

Point 2 above -- that the compartments buy electrotonic placement rather than
retinotopic sequence -- rested on ONE shuffled cable. Four independent draws,
at two global gains:

  T5 a-minus-b        chain   flipped   shuffled (4 draws)        chain/shuf
  gain 1.00          +.0641   +.0860   .0471 .0487 .0487 .0504      1.3x
  gain 1.25 (flat)   +.0447   +.0394   .0113 .0133 .0119 .0131      3.6x

The shuffle is reproducible to about 0.003, so the comparison is not noise.
And it does not say the same thing at both gains. At the gain everything else
in this project was measured at, the ordered cable beats its shuffle by 31% and
the REVERSED cable beats both, which is the "placement, not sequence" reading.
Raise the global excitatory gain by a quarter and the ordering carries most of
the effect instead: ordered 0.045, reversed 0.039, shuffled 0.012, which is the
order a correlator predicts, with the ordered cable on top.

So the honest statement is narrower than either: which of placement and
sequence dominates depends on a global gain this project does not measure. The
same sweep flips the point neuron's sign (above), so 1.25x is not obviously the
right operating point either -- it is simply a second one, and the two disagree.
Worth saying out loud in any write-up rather than quoting the gain that
flatters the hypothesis.

    python experiments/m17_dendrite.py --g-axial 8 --shuffle-seeds 4 \
        [--nmda 0.5 --nmda-k 1.0]
