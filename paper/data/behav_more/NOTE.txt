MORE SEEDS, FOR POWER

behav_fixed reports the corrected behaviour tables on 60 held-out seeds
(40-99). The fly-arena advantage there is real by its own test -- +7.53 health
and +34.0 tics against the command-matched random agent, both CIs excluding
zero -- but no model-versus-model contrast is individually significant. Intact
minus mirrored on health is +3.00 +- 6.18: a confidence interval four times
wider than the effect it is meant to bracket. That is a power problem, and only
seeds fix it.

This directory holds the same three fly-arena conditions on 60 FURTHER seeds,
100-159, for 120 in total. Same brain, same interface, same controls, same
command line; only the seeds are new, and none of them was looked at while any
of this was designed. The sky arena is not repeated, because the corrected
tables already show no effect there and doubling the seeds on a null is an
expensive way to learn nothing.

run.sh rebuilds it and is resumable: run_sharded skips every seed whose shard
already parses, so an interrupted run costs nothing but the episode it was in.

READ IT WITH

    python scripts/analyse_more.py

which pools these shards with behav_fixed's and prints the same table over the
combined seeds. Report the pooled n in anything quoted from it, since a partial
run gives a partial n and the script will happily print it.

  tics     +34.00 +-25.27    +8.02 +-29.04    +21.01 +-19.31 *

THE EFFECT REPLICATES, AND IT IS SMALLER THAN THE FIRST BLOCK SAID. Sixty
fresh seeds give half the effect of the first sixty, and neither of the new
intervals excludes zero on its own. Pooled over 120 the advantage stands and
the controls behave as before -- mirrored -0.40 health and -7.11 tics, frozen
+3.27 and +13.65, neither significant -- but the honest estimate is about a
quarter below what was published, and the first block was the favourable half.
Sixty seeds pinned this effect no better than to a factor of two. Quote the
pooled number.

WHAT MORE SEEDS DID NOT BUY. The model-versus-model contrast is still not
significant. Intact minus mirrored on health is +3.50 +- 4.63 at n=120 against
+3.00 +- 6.18 at n=60: the interval narrowed by exactly the sqrt(2) the extra
seeds buy, and still contains zero. At this effect size significance needs
about 210 seeds. That number is recorded rather than chased, because the
dissociation the project rests on is between each model and its OWN matched
control, not between models; a contrast that needs 210 seeds is not the
evidence to lean on.
